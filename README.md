# 抖音对标账号建模 · build-douyin-benchmark

给 Agent 一条公开抖音作品的分享链接，它会找到作者、整理作品列表，按实际发布时间选取最近 10 条公开可见的视频，下载发布版 MP4，提取带时码的逐字稿和分镜，最后生成这个账号专属的创作 Skill。后续可以用新 Skill 策划独立账号的人设、选题和脚本。

## 复制给你的 Agent

> 请安装 https://github.com/ZhiBoLingXi/build-douyin-benchmark 到你的用户技能目录。请按仓库的 INSTALL.md 安装并验证三个入口，完成后给我一条调用示例。

仓库根目录就是技能目录。下载、转写对齐、关键帧提取和子 Skill 打包脚本都随仓库提供。[安装说明](INSTALL.md)

## 使用示例

> 用 build-douyin-benchmark 拆解这个账号：〈粘贴一条抖音的完整分享口令〉。分析受众、人设、拍摄风格和常用结构，生成我能拿来做新账号的 Skill。

完成后，Agent 会给出形如 `douyin-playbook-<作者ID>` 的新技能名。之后可以说：

> 用刚生成的对标创作 Skill，为我的新账号出三个原创选题。先给首帧和反转，等我选定再写逐镜脚本。

| 产物 | 在哪里看 |
| --- | --- |
| 账号资料、发布时间、采样覆盖情况 | 工作目录的 `account.json` 和 `视频列表.csv` |
| 视频、带时码逐字稿、SRT、可点击关键帧的图文分镜 | 打开工作目录的 `拉片索引.html` |
| 受众推断、人设、可复用叙事结构及原创示例 | `账号与受众.md`、`创作模板.md` 和生成的专属 Skill |

语音识别和切镜先生成候选，Agent 需要回看原片并校对画面、对白与切点。公开主页少于 10 条时按实际数量处理。抖音分页受限时会记录已核对的范围及排序状态。[完整工作流程](SKILL.md)
